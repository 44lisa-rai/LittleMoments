LITTLE MOMENTS — GREEN POLAROID PHOTOBOOTH

FILES
- index.html: page structure
- style.css: green theme, layout, Polaroid styling, surprise overlay
- script.js: webcam, filters, unlimited photos, downloads, confetti interaction
- Columbine.png: optional image asset for the small surprise button

SETUP
1. Keep index.html, style.css, script.js, and Columbine.png in the same folder.
2. Open the folder in VS Code.
3. Run index.html with the Live Server extension (right-click > Open with Live Server).
4. Click "Turn on camera" and allow camera access.
5. Take as many pictures as you want. Each appears as an individual Polaroid.
6. Use "Download all Polaroids" to save them together in one image.

COLUMBINE ICON
Put your image file named exactly Columbine.png in the same folder as index.html.
If the image is not present, the button displays a small flower fallback instead.

CAMERA & PRIVACY
- Webcam access generally requires HTTPS or localhost. Opening the HTML directly as a file may block camera access.
- Photos are processed in your browser and are not uploaded to a server.
- Google Fonts need an internet connection; fallback fonts are used offline.
